# Uzi's Map Editor

1. Download: https://github.com/Uzi-Cohen/uzis-map-editor-releases/archive/refs/heads/main.zip
2. Extract the zip (right-click > Extract All).
3. Double-click `Start-Uzis-Map-Editor.bat`. If Windows warns, click "More info" > "Run anyway".

First start unpacks Java (takes a few seconds). After that it opens straight away.
